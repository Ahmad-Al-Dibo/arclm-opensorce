# Supported Architectures

ArcLM currently focuses on causal language modeling.

## Supported

- Native ArcLM compact GPT-style decoder-only causal LM.
- Hugging Face decoder-only causal LMs through `AutoModelForCausalLM`, subject to support level.

## Not Supported

- Encoder-only masked language models.
- Encoder-decoder/seq2seq models.
- Vision, audio, and multimodal workflows.
