## المقدمة (0:00 - 0:40)

السلام عليكم ورحمة الله وبركاته.

أهلاً بكم في فيديو جديد على القناة.

في هذا الفيديو سأبدأ سلسلة جديدة بالكامل، وستكون مخصصة للعمل مع نماذج الذكاء الاصطناعي الكبيرة (LLMs).

خلال هذه السلسلة سنتعلم كيف نقوم بتحميل النماذج من Hugging Face، وتشغيلها محلياً، ثم إجراء Fine-tuning عليها، وبعدها استخدام هذه النماذج داخل مشاريعنا.

اليوم سنبدأ بأول خطوة، وهي تحميل وتشغيل نموذج **Qwen 3.0 6B** باستخدام مكتبتي **ARKLM**.

إذا كنت تتابع المشروع، فستعرف أنني قبل أيام أطلقت آخر تحديث كبير للمكتبة، ومن أهم الإضافات فيه واجهة رسومية بسيطة (Simple Interface) تسمح لك بتحميل النماذج وتشغيلها بدون الحاجة إلى كتابة الكثير من الأكواد.

دعونا نبدأ.

---

## القسم الأول: تثبيت ARKLM (0:40 - 1:40)

أول شيء نحتاجه هو تثبيت المكتبة.

### اعرض الكود على الشاشة

```bash
pip install arklm
```

إذا كنت قد ثبتها مسبقاً فمن الأفضل تحديثها.

### اعرض الكود

```bash
pip install -U arklm
```

بعد انتهاء التثبيت أصبح كل شيء جاهز.

لن نكتب برنامج Python كامل، ولن نحتاج إلى إنشاء ملفات جديدة.

سنستخدم الواجهة المدمجة داخل ARKLM.

---

## القسم الثاني: تشغيل الواجهة (1:40 - 2:40)

لتشغيل الواجهة نستخدم الأمر التالي.

### اعرض الكود

```bash
python -m arklm --run simple-interface
```

أو حسب الاسم الموجود داخل المشروع.

بعد تشغيل الأمر سيبدأ Flask Server.

وستظهر رسالة تحتوي على الرابط المحلي، وغالباً سيكون:

### اعرض

```
http://127.0.0.1:5000
```

الآن بمجرد فتح الرابط داخل المتصفح ستظهر الواجهة الرسومية.

---

## القسم الثالث: خيارات التشغيل (2:40 - 3:30)

يمكن أيضاً تخصيص تشغيل الواجهة.

مثلاً تغيير المنفذ.

### اعرض

```bash
python -m arklm --run simple-interface --port 8080
```

أو تغيير الـ Host.

### اعرض

```bash
python -m arklm --run simple-interface --host 0.0.0.0
```

ويمكن دمج أكثر من خيار معاً.

### اعرض

```bash
python -m arklm --run simple-interface \
    --host 0.0.0.0 \
    --port 8000
```

وهذه الخيارات مفيدة إذا كنت تعمل على جهاز آخر داخل الشبكة أو على خادم.

## القسم الرابع: التعرف على الواجهة (3:30 - 5:00)

بعد فتح الواجهة ستلاحظ أنها بسيطة جداً.

الفكرة من هذه الواجهة ليست أن تكون مليئة بالأزرار، وإنما أن تجعل تشغيل النماذج أسرع وأسهل.

لدينا مكان لاختيار مصدر النموذج.

يمكن أن يكون النموذج من Hugging Face.

بعد ذلك تستطيع تعديل الإعدادات الخاصة بالتوليد مثل:

* درجة الحرارة (Temperature)

* Top-p
* Top-k
* وغيرها من الإعدادات التي تتحكم بطريقة توليد النص.

بعدها تضغط على زر تحميل النموذج، وتنتظر حتى يكتمل التحميل.
